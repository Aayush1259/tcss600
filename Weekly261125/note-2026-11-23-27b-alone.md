## 3. Option A: one call over the whole record, run after B

- The prompt is cloud alone's prompt (`cloud_only.py`, unchanged) with the same padded record at N = 2, in one call to qwen3.8:27b at a context of 65,536, thinking off, temperature 0, a reply budget of 300 tokens. Its reply is read by the same rule as cloud alone's; a reply with no letter is wrong.
- The reading rule of Amendment 3 section 4 (a): every call sends "truncate": false; the prompt tokens Ollama reports must equal the prompt's length counted with the model's own vocabulary plus the fixed chat template overhead measured on a short prompt; any difference halts the run. Before the warmup, one deliberately oversized prompt must be refused and one prompt sent twice must report the same count; otherwise Option A does not run.
- The call timeout is raised for A only, to the value measured on the probe times three, at least 600 seconds; it is logged.
- I report the largest prompt size, in tokens as Ollama reports it, across all calls.
- Steps: the probe (the largest record of the 200 at 65,536), one question traced, the 20 warmup questions, then the 200.
